# Документация Misbot

Начните с [обзора проекта](../README.md) или выберите задачу ниже.
Руководства установщика также доступны в скачанном комплекте: рядом с
`misbot.py` в `matrix-installer.tar.gz`, в каталоге `.misbot/` компактного комплекта.

Если устанавливаете сервер впервые, пройдите
[маршрут первого запуска и первых дней](getting-started.md).
Он связывает подготовку DNS, установку, первый вход и проверку копий.
[FAQ](faq.md) отвечает на частые вопросы о клиентах, приглашениях,
правах, ошибках и восстановлении.
