# Эксплуатация

Команды выполняет администратор своего сервера; путь установки заменяют при необходимости:

```bash
sudo misbot status
sudo misbot check
sudo docker compose --project-directory /opt/matrix-stack -f /opt/matrix-stack/compose.yaml logs --tail 100 synapse livekit jwt
df -h /opt/matrix-stack
```

При локальном MAS его журналы можно открыть той же командой, заменив список
служб на `mas`. Внешний MAS обслуживается на своей машине.

Логи могут содержать персональные данные. Не публикуйте env, ключи, дампы и конфигурации с credentials. Приватные файлы и копии защищайте владельцем и правами `0600`, каталоги — `0700`; для Windows проверяйте ACL отдельно.

Сделайте [согласованную и внешнюю защищённую копии](../installer/backup.md), проверьте восстановление и храните recovery key независимо от сервера. Прежде чем отзывать S3-доступ, проверьте новые credentials медиа и внешних копий. Контролируйте место и результаты расписания; автоматический retention не предусмотрен.

Для обычной установки проверьте опубликованные выпуски через
`sudo misbot update check`, примените последний совместимый релиз через
`sudo misbot update latest`. Можно обновить из доверенного распакованного
комплекта; условия и ограничения — в
[процедуре update](../installer/README.md#10-обновление).
Для [existing-compose](../installer/existing-compose.md) нужен проверенный
план обновления через SSH. Не редактируйте установленную версию ради обхода
проверки. После ошибки сохраните checkpoint и используйте указанную команду
recovery. Перезапуск не требует удаления БД, ключей или устройства бота.

stop сохраняет контейнеры и привязку к каталогу. down удаляет принадлежащие установке контейнеры и сеть, сохраняя данные, ключи и checkpoints. Удаление данных — отдельная операция после проверки восстановления и точного назначения.

Пароль OAuth не восстанавливает клиентские E2EE keys. Пользователь должен иметь доверенное устройство или recovery key с доступной копией клиентских ключей. Возможности фото, альбомов и сжатия определяются клиентом; сервер не перекодирует зашифрованные вложения.
