# Эксплуатация Misbot

Этот раздел нужен администратору действующего Matrix-сервера. Сначала выберите
задачу: перенос того же сервера и переход участников на новые аккаунты требуют
разных процедур.

| Задача | Руководство |
| --- | --- |
| Проверить готовность машины и принять результат на клиентах | [Требования и приёмка](requirements.md) |
| Проверять состояние, разбирать сбой, безопасно останавливать службы | [Эксплуатация](operations.md) |
| Переехать на другую машину с прежним доменом, аккаунтами и ключами | [Перенос с сохранением identity](migration.md) |
| Догрузить доступную историю исходных комнат новым аккаунтом | [Зеркалирование истории](matrix-history-mirror.md) |

Зеркалирование не переносит установку и не переименовывает старые аккаунты.
В обоих сценариях серверная копия не заменяет клиентские ключи расшифровки
истории; их восстановление проверяют отдельно.

Команды резервного копирования, восстановления и обновления — в
[руководствах копий](../installer/backup.md),
[ежедневного управления](../installer/administration.md) и
[обновления](../installer/README.md#10-обновление).
Для новой установки начните с [первого запуска](../docs/getting-started.md);
ответы на типовые вопросы — в [FAQ](../docs/faq.md).
