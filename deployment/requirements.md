# Требования и приёмка

Это контрольный список для владельца нового сервера и для проверки после
обновления или переноса. Подготовка VPS, DNS и портов подробно описана в
[инструкции установки](../installer/README.md#1-что-подготовить).
Для чужого готового стека действует отдельный контракт
[existing-compose](../installer/existing-compose.md).

## Перед развёртыванием

- Чистый VPS: Linux amd64 с systemd, Ubuntu 24.04/26.04 или Debian 12/13,
  публичный IPv4 и SSH с root/sudo.
- Практический минимум небольшой установки: 2 vCPU, 2 ГиБ физической RAM,
  SSD 20 ГиБ; не менее 10 ГиБ свободно перед первой загрузкой образов и
  3 ГиБ при дальнейшей работе. Медиа, копии и обновления требуют запаса.
  Для роста и звонков планируйте 4 ГиБ RAM и SSD 40 ГиБ.
- Постоянный Matrix-домен и управление DNS; записи и порты из
  [сетевой таблицы](../installer/README.md#2-dns-и-сетевые-порты).
  Не закрывайте действующий SSH-доступ.
- Подготовленные реквизиты выбранных внешних сервисов. Парольный вход,
  локальная PostgreSQL и локальные медиа позволяют начать без OAuth и S3.

Основная конфигурация использует локальную PostgreSQL и локальные медиа или S3.
Внешние защищённые резервные копии настраиваются отдельно. Внешняя PostgreSQL,
внешний MAS и Vault требуют своих проверок доступа, совместимости и
восстановления; их наличие в коде не подтверждает готовность внешнего сервиса.
Состав компонентов — в [архитектуре](../installer/architecture.md).

## Перед приглашением участников

Сначала выполните `sudo misbot status` и `sudo misbot check`.
Не должно оставаться незавершённых операций, службы должны работать,
а автоматические проверки — завершиться успешно. До регистрации системной
команды выполняйте их через `sudo python3 misbot.py` из проверенного комплекта
с явным `--directory /opt/matrix-stack`.

Затем проверьте реальными клиентами:

| Область | Действие и ожидаемый результат |
|---|---|
| DNS и HTTPS | Основной домен открывает сайт; чат и страница входа доступны с действующими сертификатами; Element X находит сервер по основному домену |
| Регистрация | Новый обычный аккаунт создаётся с кодом приглашения; без кода регистрация отклоняется при штатной политике приглашений |
| Авторизация и права | Работают пароль и каждый включённый OAuth-провайдер; обычный участник не получает доступа к панели администратора |
| Шифрование | Два устройства обмениваются читаемыми зашифрованными сообщениями; выполнены проверка устройства и пробное восстановление клиентских ключей |
| Медиа | Загружается и открывается новое вложение; после переноса доступны и старые вложения. При S3 проверьте выбранное хранилище по [руководству](../installer/storage.md) |
| Федерация, если подключена | После взаимного одобрения доставляются события в нужных межсерверных комнатах; состояние `connected` само по себе этого не подтверждает |
| Звонки | Звонок между двумя устройствами проходит через используемые сети, включая Wi-Fi и мобильную сеть с TURN |
| Боты | Реферальный бот выдаёт приглашение, панель отвечает разрешённому администратору, серверный помощник доставляет приветствие после принятия приглашения в личный чат |

## Готовность к сбою

Создайте копию, выполните `sudo misbot backup verify` и пройдите
[пробное восстановление](../installer/backup.md) в отдельный пустой каталог
на другой машине. Для внешней копии нужны также проверка расшифрования,
независимо сохранённый ключ и все объекты копии. При внешнем MAS отдельно
сохраните и проверьте восстановление его состояния.

Во время пробы чат и боты остаются остановленными. Для активации после реального
переноса сначала остановите источник и переключите DNS по
[руководству переноса](migration.md). Две пишущие установки с одной identity
одновременно не запускают. Пробный архив нельзя заменить финальным в том же
staged-каталоге: финальное восстановление требует нового пустого назначения.

Серверная копия не заменяет клиентские ключи зашифрованной истории.
Изолированный тест, HTTP 200 и успешное восстановление дампов не подтверждают
вход, общение и звонки в вашей конфигурации. После обновления и переноса повторите
затронутые проверки, включая чтение старых сообщений и вложений.
