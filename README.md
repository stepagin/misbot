# Misbot 1.2.0

Misbot помогает установить и обслуживать собственный Matrix-сервер для
сообщества: круга друзей, клуба, рабочей или проектной группы. Владелец управляет
сервером и доступом, участники общаются в Element на телефоне или в браузере.
Для регистрации нужен код-приглашение; его вводят в форме создания аккаунта.

Для начала достаточно уметь настроить DNS по инструкции и подключиться к серверу
по SSH. Установку и повседневное управление сопровождают пошаговый мастер и боты.

[Первый запуск](docs/getting-started.md) · [FAQ](docs/faq.md) ·
[Документация по задачам](docs/README.md)

## Что вы получите

- Matrix-сервер для сообщений, вложений и звонков, браузерный чат Element Web
  и подключение через Element X.
- Главную страницу с переходом к регистрации и чату, регистрацию по приглашениям
  и бота для выдачи кодов.
- SSH-меню и административную Matrix-панель для управления сервером,
  приветствий, объявлений и статистики.
- Локальные медиа или S3, резервные копии, обновление и восстановление.
- Подключение других серверов по согласованию. Вход через Google/Telegram
  и управляющий Telegram-бот настраиваются отдельно и необязательны.

Установщик рассчитан на **новый сервер** и не импортирует пользователей и
переписки существующей установки. Готовый Compose-стек можно подключить только
после индивидуального аудита и репетиции восстановления в
[режиме existing-compose](installer/existing-compose.md); он сохраняет
конфигурацию и версии, а набор доступных операций ограничен.

## Перед установкой

Подготовьте сервер и домен:

| Что нужно | Требования |
| --- | --- |
| VPS | Чистый Linux **amd64** с systemd: Ubuntu 24.04/26.04 или Debian 12/13 |
| Ресурсы | Практический минимум: **2 vCPU, 2 ГиБ физической RAM, SSD 20 ГиБ**; не менее 10 ГиБ свободно до установки и 3 ГиБ после неё |
| Доступ | SSH и права root/sudo |
| Сеть | Публичный IPv4, доступ к DNS домена, свободные порты и разрешённые исходящие DNS/HTTPS |

Для роста и звонков планируйте 4 ГиБ RAM и SSD 40 ГиБ, плюс запас для медиа и
обслуживания. Swap не заменяет физическую RAM. Домен выбирайте окончательно:
он станет частью адресов пользователей вида `@имя:example.org`.
Изменение домена готовой установки не поддерживается.

До запуска настройте DNS и сетевой экран по
[инструкции установки](installer/README.md#2-dns-и-сетевые-порты).
Типовая конфигурация использует основной домен и поддомены `matrix`, `mas`,
`admin`, `web`, `rtc`, `turn`, рассчитана на IPv4 и DNS без HTTP/CDN-проксирования.
Docker и необходимые системные службы настраивает установщик.

## Установка и первые проверки

В интерактивном SSH-терминале сервера выполните:

```bash
curl -fL https://github.com/stepagin/misbot/releases/latest/download/install.sh -o ~/misbot-install.sh && sudo bash ~/misbot-install.sh
```

Загрузчик доступен в релизе, содержащем `install.sh`. Он установит недостающие
пакеты, скачает последний стабильный релиз, проверит контрольные суммы и откроет
мастер. Если Misbot уже установлен, откроется меню существующей установки.
При отсутствии `curl` выполните
`sudo apt-get update && sudo apt-get install -y curl ca-certificates`.
Если загрузчик ещё недоступен или вы хотите работать с заранее полученным
комплектом, используйте
[ручную установку из архива](installer/README.md#3-загрузка-и-создание-файлов).

В мастере укажите домен, выберите хранение медиа и необходимые способы входа,
настройте резервные копии. Мастер проверит систему, DNS и порты и предложит
подтвердить запуск. Можно начать с локальных медиа и входа по паролю, а внешние
сервисы подключить позже. После инициализации команда `misbot` доступна
из любого каталога; вернуться в меню можно через `sudo misbot ui`.

Проверьте результат:

```bash
sudo misbot status
sudo misbot check
```

Службы должны работать, проверки — завершиться успешно. Если `status` сообщает
о незавершённой операции, выполните указанное действие восстановления, сохранив
данные и ключи. Повторная инициализация для устранения ошибки не нужна.

Пароль первоначального администратора `@matrix-admin:<домен>` и первый код
показываются в SSH-меню. Их также можно получить в терминале:

```bash
sudo misbot credentials admin show
sudo misbot users invitation show
```

Сохраните пароль в менеджере паролей, код передайте лично. Первое приглашение
рассчитано на одну регистрацию и по умолчанию действует 7 дней.
Для выдачи выберите **Пользователи и приглашения → Пригласить пользователя**:
после подтверждения мастер сохраняет действующий код, а использованный,
истёкший или отозванный заменяет. В CLI прерванную выдачу продолжайте через
`sudo misbot users invitation ensure`; для замены нужен явный
`sudo misbot users invitation new`. Сам `ensure` прежний код не заменяет.
Доступ к веб-панели и добавление личного администратора описаны в
[руководстве по пользователям](installer/users.md).

## Подключение участников

1. Передайте участнику адрес главной страницы `https://<домен>` и код-приглашение.
2. Новый участник выбирает **«Зарегистрироваться»**, создаёт аккаунт и вводит код
   в форме регистрации.
3. Затем он открывает чат и входит. В Element X на телефоне нужно указать
   **основной домен сервера**; браузерный чат доступен по `https://web.<домен>`.
   Участник с существующим аккаунтом сразу выбирает **«Открыть чат»**.

Приглашения можно получать в личном зашифрованном чате с
`@referral-bot:<домен>`: `пригласить` создаёт код, `токены` показывает свои
приглашения, `отозвать` позволяет отменить код. Серверный помощник
`@server-guide:<домен>` доставляет приветствия и объявления после принятия
приглашения в его личный чат.

Перед приглашением сообщества проверьте регистрацию, выбранные способы входа,
зашифрованный чат, вложение и звонок между двумя устройствами, желательно
между Wi-Fi и мобильной сетью. Успешный `misbot check` подтверждает доступность
служб, а работу в клиентах проверяйте отдельно.

## Управление сервером

| Интерфейс | Для чего использовать |
| --- | --- |
| [SSH: `sudo misbot ui`](installer/cli.md#управление-через-терминал) | Установка, настройки, приглашения, состояние, хранилища, копии, сайт, федерация, обновление и восстановление |
| [Matrix: `@admin-panel:<домен>`](installer/admin-panel.md) | Повседневное управление в личном зашифрованном чате: `помощь` открывает разделы состояния, приглашений, федерации, обслуживания и настроек |
| [Telegram-бот](bots/telegram/README.md) — по желанию | Управление одной установкой после входа через страницу авторизации сервера; администратору доступны разрешённые операции, участнику — свои приглашения |

Matrix-панель доступна первоначальному администратору и явно добавленным местным
администраторам. Она также позволяет менять приветствие, отправлять объявления
с подтверждением и получать статистику. Для обновлённых установок сохраняется
прежний адрес бота. Telegram-бот подключается по отдельной инструкции.

[Федерация](installer/federation.md) ограничена списком разрешённых серверов.
Взаимное подключение через Misbot требует независимого одобрения обеих сторон.
Управляйте заявками в панели или SSH-меню и после подключения проверяйте общение
в реальной межсерверной комнате.

## Обслуживание и ограничения

Настройте [резервные копии](installer/backup.md) до начала регулярной работы.
Храните внешнюю копию отдельно от VPS, а ключ её шифрования — отдельно от копии
и установки. Проведите пробное восстановление: наличие архива само по себе
не подтверждает пригодность копии.

Перед [обновлением](installer/README.md#10-обновление) нужны проверенная копия,
свободное место и проверка совместимости. При восстановлении сохраняются домен,
ключи и данные; перед активацией восстановленного экземпляра остановите исходный
сервер. Возврат прежней версии программы не возвращает прежнюю схему базы данных.

Учитывайте границы системы:

- Для других клиентов нужна поддержка OAuth; старые приложения могут
  не поддерживать вход.
- Серверная копия не заменяет ключи зашифрованной истории на устройствах
  участников. Сохраните клиентский ключ восстановления отдельно; вход через
  Google/Telegram его не заменяет.
- Внешние S3, OAuth и другие выбранные сервисы требуют своих настроек доступа
  и проверки на вашей конфигурации. Восстановление пароля по email недоступно
  без отдельной настройки почты.

Для ежедневных действий и ошибок начните с
[памятки администратора](installer/administration.md).
Ответы на частые вопросы — в [FAQ](docs/faq.md), полная навигация по установке,
управлению, переносу и устройству системы — в [документации по задачам](docs/README.md).

## Исходники, сборка и проверки

| Путь | Назначение |
| --- | --- |
| [`installer/`](installer/) | Переносимый установщик, CLI, сайт и тесты |
| [`bots/telegram/`](bots/telegram/) | Telegram-бот и общая управляющая служба |
| [`bots/matrix-referral/`](bots/matrix-referral/) | Matrix-бот приглашений |
| [`bots/matrix-federation/`](bots/matrix-federation/) | Административная Matrix-панель |
| [`deployment/`](deployment/) | Эксплуатация, перенос и инструмент зеркалирования истории |
| [`ci/`](ci/) | Проверки качества, тесты и проверка сборки |

Из корня репозитория:

```bash
python3 installer/build.py  # архивы и контрольные суммы в dist/
python3 ci/check.py all     # качество, тесты, shell-синтаксис и проверка сборки
```

Локальная сборка получает суффикс `-build.N`; базовая версия исходников не меняется.
Код рассчитан на Python 3.11–3.14 и Node 24. Полные проверки требуют зависимостей
разработки, интеграционные тесты установщика — отдельной контейнерной среды.
Локальные тесты не заменяют приёмку регистрации, входа, федерации, звонков
и восстановления на целевой конфигурации.
