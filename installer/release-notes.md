# Misbot 1.1.1

- Существующий Compose-стек может управлять зарегистрированными контейнерами Caddy
  и Telegram worker через `start`, `stop`, `status` и `check`.
- Проверка, применение и восстановление сайта используют выбранный Caddy runtime.
  Сохраняются индивидуальный шаблон сайта, TLS и Matrix identity.
- Telegram worker получает только собственные настройки, SQLite и управляющий
  сокет. Привилегированная управляющая служба остаётся на хосте.
- Резервная копия сохраняет актуальные настройки контейнерного worker и согласованный
  SQLite snapshot. Обновление изменённых исходников автоматически собирает и проверяет
  новый worker image, сохраняет прежний pin и восстанавливает его при сбое.

Обновление с 1.1.0 сохраняет прежний режим служб. Перенос существующих systemd-служб
в Compose выполняется отдельно после инвентаризации и проверки восстановления.
Новые поля инвентаризации необязательны; формат конфигурации и схема данных остаются
прежними. Домены, issuer, базы, сессии и ключи ботов не перегенерируются.

# Misbot 1.1.0

- Исходники доступны под лицензией MIT, автор — Stepan Ponamarev; текст лицензии входит
  в установочный архив.
- Административный бот `@admin-panel`, доступный только владельцу сервера;
  удобные команды, уведомления о версиях и регистрации, статистика.
- Обновление из готового GitHub Release с проверкой диска, подтверждением
  и сохранённым отчётом; автоматические транзакционные миграции данных панели.
- Приветственный бот `@server-guide`, редактируемое приветствие и рассылки
  с предварительным просмотром и подтверждением администратора.
- Многоэтапное удаление сервера, включая незавершённую установку и выбранные
  внешние данные; утилита сохраняется.
- Команды панели нечувствительны к регистру, тексты и идентификаторы сохраняются.

Обновление сохраняет домен, ключи, настройки, историю сообщений и отметки
доставки. Произвольная смена версий компонентов и major PostgreSQL не
поддерживается; допустимые переходы и recovery описаны в README комплекта.
Число и длительность зашифрованных звонков MatrixRTC в статистике недоступны.
